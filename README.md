# 오늘 어때 (v4.22 · Vercel용)

(이전 이름: 우리 학교 오늘. 저장소·파일 묶음 이름은 `school-today` 그대로입니다.)

내 위치(GPS·와이파이) 또는 접속 IP로 가까운 학교를 찾아, 그 학교의 오늘·내일 급식과 날씨·미세먼지·기상특보를 한 화면에 보여 주는 사이트입니다. 전국 초·중·고 12,004곳을 지원합니다.
v3.1에 **공지 기능**을 더한 버전입니다. 구글 스프레드시트에 오늘 띄울 공지가 있으면 '내일 급식' 칸이 노란 공지 칸으로 바뀝니다.

## 폴더 구성
- `public/index.html` — 화면 (학교 고르기 + 오늘의 학교)
- `public/warnings.html` — 점검용 페이지 (기상특보 원본·해석 결과, 미세먼지 측정소·내일 예보 권역)
- `public/manifest.json`, `public/icon-*.png`, `public/apple-touch-icon.png` — 홈 화면 앱 설정과 아이콘
- `api/schools.js` — 학교 찾기 (위치·IP·이름 검색·ID) → `/api/schools`
- `api/meal.js` — 급식 (나이스) → `/api/meal`
- `api/weather.js` — 날씨(기상청) + 미세먼지(에어코리아 측정값·내일 예보) + 특보 반영 + 운동장 신호등 → `/api/weather`
- `api/warnings.js` — 기상특보 (화면이 20분마다 따로 확인) → `/api/warnings`
- `api/notice.js` — 공지 (선생님의 구글 시트 읽기, 인증키 필요 없음) → `/api/notice`
- `lib/notice-core.js` — 시트(CSV) 해석·날짜 조건 (글자 수·건수 제한은 이 파일 맨 위)
- `public/notice.html` — 공지 설정 안내 페이지 (시트 링크를 붙여넣으면 주소와 QR 코드를 만들어 줌)
- `public/qrcode.js` — QR 코드 그리기 (qrcode-generator 2.0.4, MIT 라이선스 · Kazuhiko Arase)
- `lib/warnings-core.js` — 특보 해석·학교 지역 매칭 (반영할 특보 목록은 이 파일 맨 위)
- `data/schools.csv` — 전국초중등학교위치표준데이터 (공공데이터포털 원본 CSV)
- `tools/build-schools.mjs` — 배포할 때 CSV를 `generated/schools.json`으로 자동 변환
- `vercel.json` — 빌드 명령, 화면 폴더(public), 함수 지역(서울 `icn1`)
- `package.json` — Node.js 22, ES 모듈 설정

## Vercel에 올리기 (처음 한 번)
1. GitHub에 새 저장소를 만들고 이 폴더의 **내용물 전체**를 올립니다 (`api`, `public`, `vercel.json` 등이 저장소 첫 화면에 보이도록).
2. vercel.com 에 GitHub 계정으로 로그인 → **Add New… → Project** → 방금 만든 저장소 **Import**.
3. 설정 화면에서
   - **Framework Preset**: `Other` (빌드 명령·출력 폴더는 `vercel.json`이 알아서 채움)
   - **Environment Variables**에 아래 두 개 추가
4. **Deploy** 를 누르면 `https://(프로젝트이름).vercel.app` 주소가 생깁니다.

## 환경변수 (Vercel → Project → Settings → Environment Variables)
- `NEIS_API_KEY` — 나이스 교육정보 개방 포털 인증키
- `DATA_GO_KR_KEY` — 공공데이터포털 일반 인증키(Decoding). 아래 4개 서비스 활용신청 필요
  - 기상청_단기예보 ((구)_동네예보) 조회서비스
  - 한국환경공단_에어코리아_대기오염정보
  - 한국환경공단_에어코리아_측정소정보
  - 기상청_기상특보 조회서비스

환경변수를 바꾼 뒤에는 **Deployments → 맨 위 배포의 ⋯ → Redeploy** 로 다시 배포해야 적용됩니다.

## Netlify(v2)와 달라진 점
| | v2 (Netlify) | v3 (Vercel) |
|---|---|---|
| 함수 위치 | `netlify/functions/*.mjs` | `api/*.js` |

| 무료 플랜 배포 | 1회 15크레딧 (월 약 20회) | 하루 100회 |

화면 주소 규칙(`?s=학교ID`, `&nav=0`, `&awake=0830-1500`)은 그대로입니다.

## 화면 구성
- **날씨 칸 (순수 날씨)**: 지금 기온·습도, 오늘 최저/최고, 지금 시각 강수확률(비가 오는 동안은 1시간 강수량), 미세먼지·초미세먼지, 내일(하루 전체) 날씨와 **내일 미세먼지 예보**
- **운동장 신호등 (학교 생활 기준, 등하교 7:30~16:30)**
  - 0:00~16:29 오늘 기준 / 16:30~24:00 **내일 기준** ("내일 ⚠️ …")
  - ❌ 실내 권장: 미세먼지 '나쁨' 이상, 지금 비/눈, 최고 33℃ 이상, 경보
  - ⚠️ 주의: 등하교 시간 비 예보, 강수확률 60% 이상, 새벽 비, 31~32℃, -5℃ 이하, 강풍 9m/s 이상, 주의보
  - 내일 기준일 때 내일 미세먼지 예보가 '나쁨' 이상이면 ⚠️ (예보는 권역 단위 등급이라 ❌ 까지는 올리지 않음)
  - 내일 기준일 때 지금 발효 중인 경보는 ⚠️ 로 한 단계 낮춤
- **기상특보**: 강풍·호우·대설·태풍·폭염·한파·황사만 반영 (풍랑·건조·폭풍해일 제외). 경보·태풍은 빨간 띠로 강조
- **급식**: 오늘·내일. 쉬는 날에는 "쉬는 날이에요", 다음 급식은 '내일' 칸에만 한 번. ‹ › 로 급식 있는 날만 넘겨 보기, 1분 동안 안 만지면 오늘로 복귀
- **화면 크기**: 내용이 길면 자동으로 줄여 한 화면에 맞춤(최소 80%). 높이 520px 이하 가로 화면(800×480 등)은 3단 배치
- **큰 화면**: 가로 700px 이상·세로 860px 초과 화면(교실 TV·전자칠판·큰 모니터)은 화면에 가득 차게 키움. 가로 1400px 이상 와이드 화면(1920×1080 등)은 3단 배치로 키움. 1024×768·800×600·800×480 등 기존 크기는 그대로

## 갱신 주기
| 상황 | 동작 |
|---|---|
| 접속·브라우저 새로고침·'새로고침' 버튼 | 급식·날씨·특보 모두 바로 불러옴 |
| 켜 둔 화면, 낮 6~18시 | 날씨 매시 20분 · 특보 20분마다 · 급식 3시간마다 · 공지 5분마다(7:30~16:30, 그 밖의 낮은 30분) |
| 16:30 | 신호등을 내일 기준으로 전환 (다시 불러오지 않음) |
| 켜 둔 화면, 밤 18~6시 | 쉼 |
| 자정 0:01 | 급식·날씨 새로 불러와 날짜를 넘김 |
| 꺼졌던 화면이 다시 켜질 때 | 오래된 것만 바로 다시 불러옴 (날씨 1시간·급식 3시간·특보 20분 기준) |
| 갱신에 실패했을 때 | 마지막으로 받은 값을 그대로 두고 "○시 ○분 기준" 표시. 2·5·10분 뒤 다시 시도, 인터넷이 다시 연결되면 바로 다시 받음. 날씨는 같은 날 3시간 안의 값만 대신 보여 줌 |

서버 캐시: 급식 30분, 날씨는 다음 '매시 15분'까지, 특보 10분, 학교 목록 하루. 내일 미세먼지 예보(하루 4번 발표)는 함수 안에서 30분 기억.

## 학교별 바로가기 주소
- 학교를 고르면 주소가 `…/?s=학교ID` 로 바뀝니다. 이 주소를 즐겨찾기하거나 QR로 만들면 그 학교가 바로 열립니다.
- 터치가 안 되는 화면(라즈베리파이 + HDMI 모니터 등)은 `&nav=0` 을 붙이면 넘기기 버튼이 숨겨집니다.
- 교실 태블릿처럼 화면을 켜 둘 때는 `&awake=0830-1500` 을 붙이면 평일 8:30~15:00 동안 화면이 꺼지지 않습니다.

## 공지 칸 (구글 스프레드시트)
- 화면 맨 아래 **공지 설정**(`/notice.html`)을 열어 안내대로 하면 됩니다.
  1. 구글 스프레드시트 첫 번째 시트에 A열 = 공지 내용, B열 = 시작일(선택), C열 = 종료일(선택)
  2. 공유 → **링크가 있는 모든 사용자 · 뷰어** → 링크 복사
  3. 설정 페이지에 붙여넣으면 `…/?s=학교ID&notice=시트ID` 주소가 만들어짐 → 이 주소로 열어 즐겨찾기
- 주소에 `notice=` 가 없으면 지금과 똑같습니다. 공지는 화면(주소)마다 따로 연결됩니다.
- **오늘 띄울 공지가 있는 날만** '내일' 칸이 공지 칸으로 바뀌고, 없는 날은 내일 급식이 나옵니다. 오늘 급식 칸은 늘 제자리입니다.
- 공지 칸이 켜진 날은 ‹ › 가 둘 다 급식 칸에 있고, 급식 칸만 하루씩 넘어갑니다(공지는 그대로). 1분 동안 안 만지면 오늘로 복귀.
- 날짜를 비우면 계속 · 시작일만 있으면 그날부터 · 종료일만 있으면 그날까지. 한 건 80자, 화면에는 8건까지. 날짜 없는 공지를 계속 두면 내일 급식이 계속 가려지니 종료일을 적는 것이 좋습니다.
- **다른 기기에서 열기**: 설정 페이지의 QR 코드를 찍으면 됩니다. 한 번 연 기기는 시트를 기억해서, 다음부터는 짧은 주소(`…/?s=학교ID`)로 열어도 공지가 나옵니다. 학교를 바꿔도 기억은 그대로입니다. 끊으려면 설정 페이지의 **이 기기에서 공지 끄기**(또는 주소에 `&notice=0`).
- **확인 주기**: 7:30~16:30은 5분마다(서버 보관 2분 → 최대 7분쯤), 6:00~7:30·16:30~18:00은 30분마다, 밤에는 쉼. '새로고침' 버튼은 보관분을 건너뛰고 바로 반영. 읽기에 실패하면 마지막 공지를 그대로 둡니다.
- 우리 서버에는 공지를 저장하지 않습니다. 링크를 아는 사람은 시트를 읽을 수 있으니 **학생 이름·개인 사정은 적지 마세요.**

## 홈 화면에 앱처럼 추가하기
- 학교 화면을 연 상태에서 브라우저 메뉴의 **홈 화면에 추가**(또는 **앱 설치**)를 누르면, 아이콘이 생기고 주소창 없이 전체 화면으로 열립니다.
- 추가할 때 보고 있던 주소(학교·`nav`·`awake` 옵션)가 그대로 시작 주소가 됩니다. 옵션을 바꾸려면 원하는 주소로 연 뒤 다시 추가하세요.

## 알레르기 표시
- 화면 맨 아래 **알레르기 표시**를 눌러 식품(난류·우유·땅콩 등 19가지)을 고르면, 그 식품이 든 메뉴 줄이 색으로 표시됩니다.
- 선택은 그 기기(브라우저)에만 저장되고 서버로 보내지 않습니다. 표시는 학교가 나이스에 올린 알레르기 정보를 그대로 따릅니다.

## 학교 자료 새로 고치기
1. 공공데이터포털에서 「전국초중등학교위치표준데이터」 CSV를 새로 내려받습니다.
2. GitHub의 `data/schools.csv`를 새 파일로 바꿔 올립니다 (파일 이름은 `schools.csv` 그대로).
3. Vercel이 자동으로 다시 배포하면서 변환합니다. 화면 맨 아래 '데이터기준일'이 바뀌면 완료.

## 알아둘 점
- **내일 미세먼지 예보**는 에어코리아 '대기질 예보통보'(이미 신청한 「대기오염정보」 서비스에 포함)를 씁니다. 19개 권역 단위 등급이며, 경기(북부/남부)·강원(영서/영동)은 학교 주소의 시·군으로 나눕니다. 권역이 맞게 잡혔는지는 `/warnings.html` 에서 확인할 수 있습니다.
- Vercel 무료(Hobby) 플랜은 **비상업적·개인 용도** 조건이 있습니다.
- 무료 플랜은 함수 지역을 **한 곳만** 고를 수 있어 서울(`icn1`) 하나로 지정했습니다. 배포가 지역 문제로 실패하면 `vercel.json`의 `"regions"` 줄을 지우고 다시 배포하세요(기본값 미국 동부로 돌아감).
